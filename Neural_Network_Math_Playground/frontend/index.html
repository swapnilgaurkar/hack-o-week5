Eigenvalues — Intuition

A matrix can transform a vector by rotating, stretching or shrinking it. An eigenvector is a special direction that stays on the same line after the transformation. Its scaling factor is the eigenvalue.

A = [ 2 0 ]
    [ 0 3 ]
→
[1, 0] → [2, 0]
[0, 1] → [0, 3]

For this matrix, the eigenvalues are 2 and 3. The directions along the x-axis and y-axis remain unchanged; only their lengths change.

Chain Rule

x
→
z = 2x
→
y = z²

dy/dx = (dy/dz) × (dz/dx)

Here, dy/dz = 2z and dz/dx = 2, so dy/dx = 4z = 8x.

This is the key idea behind backpropagation: break a complicated calculation into smaller derivatives and multiply them together.
