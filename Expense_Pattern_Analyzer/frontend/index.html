Learn the concepts

Perceptron

One artificial neuron: multiply each input by a weight, add them up, add a bias, then decide. Example: inputs 0.8 and 0.3, weights 0.9 and −0.5, bias −0.2 give 0.72 − 0.15 − 0.2 = 0.37, which is above 0, so it outputs 1.

Forward propagation

Data flows left to right: 5 inputs → 8 hidden neurons → 1 output. Each layer does weighted sums plus bias, then an activation. The final sigmoid gives a probability between 0 and 1.

Activation functions

Without them the network could only draw straight lines. ReLU keeps positives and zeroes negatives. Tanh squashes values between −1 and 1. Sigmoid squashes into 0–1, perfect for probabilities.

Loss calculation

Loss is a score for how wrong the guesses are. We use binary cross-entropy: it punishes confident wrong answers heavily. Lower is better.

Backpropagation

After a wrong guess, the error is sent backwards through the layers using the chain rule, giving each weight a gradient: “which direction, and how much, should I change to reduce the loss?”

SGD

Stochastic gradient descent nudges every weight a small step (the learning rate) opposite its gradient, using small random batches of examples.

Adam

Adam also remembers a running average of past gradients (momentum) and of their squares, so each weight gets its own adaptive step size. It often trains faster with less tuning.

Serialization & inference

After training, the weights, biases, settings and scaling numbers are saved to a file with Joblib. Loading restores them so predictions work instantly without retraining. Only load model files you created yourself.
